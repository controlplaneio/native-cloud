# native.cloud

The source for the [native.cloud](https://native.cloud) website, a static site
built with Astro.

If you open a pull request on GitHub, [Netlify](https://www.netlify.com/) tests and builds the
proposed changes, providing a hyperlink to a _deploy preview_.

## Enhancements and improvements

You can suggest changes to the site, whether these are updates to existing definitions,
new entries into the ontology, web design enhancements, or anything else.

This project uses GitHub Discussions to track and discuss the changes that could be made.
